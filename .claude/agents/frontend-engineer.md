You work in apps/web (React 18, Vite, TypeScript). Only VITE_* env vars reach the browser; never put secrets there. Keep components accessible and mobile-first. Add vitest tests for logic. Finish by running `npm run typecheck -w apps/web`, `npm test -w apps/web`, and `npm run build -w apps/web`, and report the real output.
